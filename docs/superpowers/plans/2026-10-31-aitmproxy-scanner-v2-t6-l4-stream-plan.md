## Overview

T6 fills the `aitm-scan-l4-stream` skeleton that T1a handed over: a grammar format and eight grammars, a seedable mutation engine, an unprivileged TCP/UDP client behind the L4 guard, a per-job state with pacer/semaphore/liveness bookkeeping, a probe host, three checks over one shared campaign, and the `Lane` implementation that flips `lane()` to `Some`. Everything lives under `crates/aitm-scan-l4-stream/**` (spec Constraints); no other path is edited except, in the integration task, a possible re-pin of the integration-shared contract files and the `report_l4` wiring. Work fans out along S1's module tree: one task owns one file (or one pair of grammar files), so coders inside a wave never share a file.

| F8 | A crash retires the field path on its node for every seed (matching the L4 dedupe key), so one crashing `len` path costs one reproduction round, not one per seed (`state.rs`, `host.rs`, `checks.rs`). |

## Architect's calls in this plan (for the orchestrator/Matt to approve or correct)

- **P1** `codec.rs` (hex, base64, FNV-1a, CRC-32, internet checksum) is a module in its own right rather than part of `corpus.rs` as S1 lists, so decoders can land in wave 2 with no grammar dependency; `grammars/mod.rs` exists for the registry's `pub mod` lines. S1's table is read with these two additions.
- **P2** `Ended` is defined in `client.rs` (Task 14) and re-exported from `grammar.rs` (`pub use crate::client::Ended`), so `Expect::matches` and the client agree on one type. (Inverted at stage 6 from the original wording, which had the definition in `grammar.rs`; the code and the spec's S3 now say `client.rs`.)
- **P3** Three small trait additions with default bodies beyond the S3 sketch: `Grammar::prelude_for(&self, case: &[u8])` (MQTT: no CONNECT prelude when the case is a CONNECT), `Grammar::expects_banner(&self)` (SMTP/FTP read the 220 first), `Exchange.after: Option<Vec<u8>>` (MQTT DISCONNECT / line `QUIT` after the liveness reply).
- **P4** A clean reply is `ProbeResponse { l4: None, body: reply }`; an oracle reading is `l4: Some(L4Reply { .. })`, because `L4Reply.oracle` is not optional in the T1a model and inventing an `Ok` oracle would be a model change.
- **P5** Because `Campaign` holds only `&dyn ProbeHost`, the liveness/recovery probe is exposed by `StreamHost::probe` as a reserved payload (`bytes: None`, `value: "liveness"`) that routes to `liveness_twice`; everything else in the reproduction loop is ordinary `probe` calls on the identical case bytes, so the campaign stays a pure consumer of the trait.
- **P6** Tasks 21/22 SKIP loudly (not fail) when the sandbox refuses to bind loopback, and the Tester runs them in the Terminal; the default gate therefore stays hermetic in the sandbox and complete in the Terminal.
- **P7** Task 23 is deferred, not faked, if T10's speakers and cells are not mergeable when T6 reaches wave 10; the PR is then opened as a draft.
