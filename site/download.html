Get aitmproxy v0.5.20

Install the aitm binary — core proxy, web UI, terminal UI and MCP server — with Homebrew on macOS (Apple Silicon), or take a native package or tarball on Linux. The macOS app bundles its own core. Licensed under MIT or Apache-2.0. macOS and Linux only; there is no Windows build.

Showing

Homebrew

On macOS (Apple Silicon), tap the project, then install the aitm binary — web UI and embedded browser bundled in — or the notarized app as a cask.

$ brew tap mrbrutti/aitmproxy
$ brew install aitm
$ brew install --cask aitmproxy

The formula is the aitm core with its web and terminal UIs; the cask is the macOS app, which bundles and manages its own core. Both are Apple Silicon only. The tap and the release assets are public, so no token is needed. On Linux, use a native package or tarball below.

Native package

On Linux, download the package for your distribution and install it. It puts aitm and aitm-tui on your PATH with the embedded browser alongside. The file names below match your CPU; the full list is further down.

$ curl -LO https://github.com/mrbrutti/homebrew-aitmproxy/releases/download/v0.5.20/aitm-0.5.20-amd64.deb
$ sudo apt install ./aitm-0.5.20-amd64.deb # Debian / Ubuntu
$ curl -LO https://github.com/mrbrutti/homebrew-aitmproxy/releases/download/v0.5.20/aitm-0.5.20-x86_64.rpm
$ sudo dnf install ./aitm-0.5.20-x86_64.rpm # Fedora / RHEL

Packages exist for x86-64 and aarch64; a plain .tar.gz of the binaries is in the table below. The release assets are public, so no token is needed. On macOS, use Homebrew instead.

Then capture.

Trust the local certificate once, start the web UI, and point your app, browser or client at 127.0.0.1:8080.

$ aitm ca install
$ aitm web

aitm web serves the UI on 127.0.0.1:8082 and prints a one-time web UI (agent): http://127.0.0.1:8082/#t=… link; open it in a browser, since nothing opens for you. Prefer the terminal? aitm tui starts the core and the TUI together. Getting started, step by step

Cargo and from source

With a recent Rust toolchain you can install the aitm binary directly. The source repository is private, so this needs git credentials with access to it. A bare cargo build produces aitm only: no aitm-tui, no bundled obscura browser engine, and no embedded web UI unless apps/web was built first. The packaged builds above include all three.

$ cargo install --git https://github.com/mrbrutti/aitmproxy aitm

Every face, every platform.

One core, written in memory-safe Rust. Pick the surface that fits the moment; they all speak to the same proxy.

Web & CLI

The aitm binary ships the SolidJS web UI and every command, and serves MCP over stdio when run with no arguments. Runs on macOS and Linux.

aitmproxy

A fast, memory-safe intercepting proxy for inspecting and editing HTTP, WebSocket, HTTP/2 and raw L4 traffic during development and authorized testing. Use it on systems you own or are permitted to test.
