Get aitmproxy v0.5.0

The first release. Install the aitm binary — core proxy, terminal UI, web UI and MCP server — with Homebrew or Cargo, grab a native Linux package, or build from source. The macOS app ships the same core. Everything is open source, MIT or Apache-2.0.

Homebrew

On macOS (Apple Silicon), tap the project, then install the aitm binary — web UI and embedded browser bundled in — or the notarized app as a cask.

$ brew tap mrbrutti/aitmproxy
$ brew install aitm
$ brew install --cask aitmproxy

The formula is the CLI and the three UIs; the cask is the macOS app, which drives the same core. The tap and the release binaries are public — no token needed. On Linux, use a native package below, or Cargo.

Then capture.

Trust the local certificate once, start the proxy, and point your app, browser or client at 127.0.0.1:8080.

$ aitm ca install
$ aitm web

Prefer the terminal? aitm tui starts the core and the TUI together. Getting started, step by step

Packages and archives

Prefer a native package or a plain archive? The v0.5.0 release attaches a .deb, an .rpm and a .tar.gz for Linux (x86-64 and aarch64), with a signed macOS .dmg following once notarization is set up. Each asset is listed below with its SHA-256 the moment the release finishes publishing.

The table above fills in from the release manifest. If it is empty, the v0.5.0 artifacts are still publishing — check back shortly, or use Homebrew above, Cargo, or build from source in the meantime.

Cargo and from source

With a recent Rust toolchain you can install the aitm binary directly, or clone and build. A bare cargo build produces aitm; the packaged builds above add the aitm-tui and embedded browser alongside it.

$ cargo install --git https://github.com/mrbrutti/aitmproxy aitm

aitmproxy

A fast, memory-safe intercepting proxy for inspecting and editing HTTP, WebSocket, HTTP/2 and raw L4 traffic during development and authorized testing. Use it on systems you own or are permitted to test.
