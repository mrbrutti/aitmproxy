Install in one line. Capture in three.

One Homebrew formula puts the core proxy, the terminal UI, the web UI and the MCP server on your machine. The macOS app is a cask that ships the same core. Everything is open source.

Homebrew

macOS 13+ (Apple Silicon and Intel) and Linux (x86-64 and arm64). The formula installs the aitm binary with the web UI and the embedded browser bundled in — nothing else to fetch.

$ brew install aitmproxy
$ brew install --cask aitmproxy

The first line is the CLI and the three UIs. The second is the notarized macOS app, which drives the same core.

Then capture.

Trust the local certificate once, start the proxy, and point your app, browser or client at 127.0.0.1:8080.

$ aitm ca install
$ aitm web

Prefer the terminal? aitm tui starts the core and the TUI together. Getting started, step by step

aitmproxy

A fast, memory-safe intercepting proxy for inspecting and editing HTTP and WebSocket traffic during development and authorized testing. Use it on systems you own or are permitted to test.
