Getting started

Ten minutes from an empty terminal to a request held in mid-air and edited, first by you, then by an assistant. Everything here works the same in the macOS app, the web UI and the terminal UI.

Install

aitmproxy installs with Homebrew on macOS and Linux. The formula ships the aitm command, the terminal UI, the web UI and the MCP server. The macOS app is a separate cask that includes the same core.

Prefer the app? brew install --cask aitmproxy puts aitmproxy.app in Applications. The app starts the same core and can be driven by the same CLI.

Trust the certificate

To read HTTPS, aitmproxy terminates TLS with a certificate authority it generates on your machine, for your machine. Nothing leaves your computer. Before browsers and apps will accept it, that CA must be trusted.

By agent: an assistant connected over MCP can call ca.status() and ca.export(), but ca.install is a human-only command. Trust decisions stay with the person at the keyboard.

For a device that is not this machine (a phone, a VM), export the certificate with aitm ca export --out aitm-ca.pem and install it there by the device's usual means. Hosts that pin their certificates can be excluded with TLS passthrough.

Capture

Start the proxy. It listens on 127.0.0.1:8080 and serves the web UI on 127.0.0.1:8082. Point a browser, a simulator or your app at the proxy and flows start arriving.

The macOS app and the terminal UI (aitm tui) show the same list live. Select a flow to read the request and response, headers and body, timing and the TLS details of the connection.

ShortcutAction
/Filter flows by method, host, path or status
↩Resume the selected held flow
⌫Drop the selected held flow
RReplay the selected flow
IArm interception for the selected flow's path

Intercept and edit

Interception pauses a request in mid-air. Add a rule for the traffic you care about, trigger it from the app, and the flow appears as armed: readable and editable, going nowhere until you say so.

In the app, the same four moves are: select the held row, edit the body in the detail pane, press ↩ to resume or ⌫ to drop. Response interception works the same way; add --hold response to the rule and the response pauses on its way back.

aitmproxy

A fast, memory-safe intercepting proxy for inspecting and editing HTTP and WebSocket traffic during development and authorized testing. Use it on systems you own or are permitted to test.
