One flow, three verbs

Every interaction is a typed Flow. Interception is a pausable future: a flow is observed, parked for edits, then resumed or killed — the same lifecycle on HTTP and WebSocket.

Everything you reach for, in one proxy

mitmproxy- and Proxyman-class parity, built as plugins over a thin core.

Intercept & edit

Park flows by rule — URL, method, host, phase — and edit the request or the response before it lands.

Kill modes

Abort a parked flow as a connection reset, or synthesize a 429/503 with no upstream call.

Map Local & Map Remote

Serve a local file as the response, or rewrite a request's target host before it goes upstream.

WebSocket control

Compose and inject frames onto a live socket; intercept, edit or drop frames in flight.

Sessions & HAR

Save and load sessions; import and export HAR 1.2 and mitmproxy .flows.

TLS passthrough

Tunnel chosen hosts byte-for-byte instead of decrypting them — for pinned apps.

One command surface. Two operators.

Every deterministic capability is a registered command. The CLI, the three UIs and the MCP server all invoke the same commands — so an AI agent can drive 100% of the tool, and the only difference is the origin tag in the audit log.

Hold the agent at all, read-only, or paused from any UI. The agent can't un-pause itself.

operator · terminal
$ aitm flow mutate --id 42 --set-body '{"sku":"A-1042","qty":999}'
# parked at request · edit applied · flow.resume to forward

Observe, act, reproduce

Find a flaw by hand or let an agent explore — then turn the finding into a self-contained PoC that reruns with only aitmproxy.

First, list what the proxy has seen.

$ aitm flow list --host shop.example.com

Then replay a candidate through the guarded client.

$ aitm request send --from 42 --set qty=999

Finally, build and run a PoC. It writes three artifacts.

$ aitm poc build --from 42 --out cart-overflow.yaml
$ aitm poc run cart-overflow.yaml
# → finding capture · cart-overflow.yaml · screenshot.png

Three UIs. One bus.

All three are thin clients of the same command bus. One token vocabulary styles every surface.

macOS

Native SwiftUI

Fully native Swift/SwiftUI with an AppKit table for the dense flow list. No web view, no Electron.

Web

SolidJS

A SolidJS UI built once and embedded in the binary; aitm web serves it over a WebSocket bridge.

Terminal

ratatui TUI

One Rust binary for macOS and Linux. Keyboard-complete; degrades gracefully to a DOM outline.

Two languages, made to read

Extend the proxy in Rhai, and capture findings as declarative PoC YAML. Both are written to be read and written by people, not only agents.

addons/guard-admin-writes.rhai
fn on_request(flow) {
    let req = flow.request;
    if req.path.starts_with("/admin") && req.method != "GET" {
        if !req.headers.has("X-Admin-Token") {
            flow.set_response(403, #{}, "blocked by aitm");
            return halt();
        }
    }
}
