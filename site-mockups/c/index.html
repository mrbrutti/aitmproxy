One command surface. Two operators.

Every capability is a registered command. The CLI, all three UIs and the MCP server invoke the same ones — so an AI can drive 100% of the tool. The only difference is the origin in the audit log, and the agent can't un-pause itself.

By hand operator · terminalorigin: cli
$ aitm flow mutate --id 41 \
    --set-body '{"sku":"A-1042","qty":999}'
# edit applied · parked at request
By agent MCP tool callorigin: mcp
flow.mutate({ id: 41,
  set_body: '{"sku":"A-1042","qty":999}' })
# edit applied · parked at request
→ both resolve to the same flow #41, held at the request phase, logged to the same audit trail.

Observe, act, reproduce

Find a flaw by hand or let an agent explore — then turn the finding into a self-contained PoC that reruns with only aitmproxy and writes three artifacts.

$ aitm flow list --host shop.example.com
$ aitm request send --from 41 \
    --set qty=999
$ aitm poc build --from 41 \
    --out cart-overflow.yaml
$ aitm poc run cart-overflow.yaml

Three surfaces. One bus.

All three are thin clients of the same command bus. One token vocabulary styles every surface; a human connects with the operator token, never the agent's.

macOS app

Swift · SwiftUI · AppKit table

Fully native — a dense flow list in an NSTableView. No web view, no Electron.

Web UI

SolidJS · aitm web

Built once and embedded in the binary; served over a WebSocket bridge at native-grade snappiness.

Terminal (TUI)

Rust · ratatui · aitm tui

One binary for macOS and Linux. Keyboard-complete; degrades gracefully to a DOM outline.

Two languages, made to read

Extend the proxy in Rhai, and capture findings as declarative PoC YAML. Both are written to be read and written by people, not only agents.

Rhai plugin

A default-deny sandbox; every hook optional; JS-like idioms. Load it without recompiling the core.

addons/guard-admin-writes.rhai
fn on_request(flow) {
    let req = flow.request;
    if req.path.starts_with("/admin")
        && req.method != "GET" {
        if !req.headers.has("X-Admin-Token") {
            flow.set_response(403, #{}, "blocked");
            return halt();
        }
    }
}
