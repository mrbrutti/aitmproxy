A proxy you can hand to an agent.

aitmproxy is a fast, memory-safe Rust intercepting proxy for authorized security testing. It captures, edits and replays traffic — and exposes every command to a person or an AI, over the same bus.

One flow, three verbs

Every interaction is a typed Flow. Interception is a pausable future — the same lifecycle on HTTP and WebSocket.

Observed

Captured and stored, streamed by default so memory stays flat under load.

Intercepted

Parked by rule at the request or response phase. Edit method, path, headers, body or status; a reverted copy is kept.

Resumed or killed

Forward with edits, or abort as a reset — or synthesize a 429/503 with no upstream call.

One command surface. Two operators.

Every capability is a registered command. The CLI, the UIs and the MCP server invoke the same ones — so the agent can drive 100% of the tool, and the only difference is the origin in the audit log. Hold it at all, read-only, or paused; it can't un-pause itself.

operator · terminal
$ aitm flow mutate --id 42 --set-body '{"sku":"A-1042","qty":999}'
# parked at request · edit applied · flow.resume to forward

Observe, act, reproduce

Find a flaw by hand or let an agent explore — then turn it into a self-contained PoC that reruns with only aitmproxy and writes three artifacts.

$ aitm flow list --host shop.example.com
$ aitm request send --from 42 --set qty=999
$ aitm poc build --from 42 --out cart-overflow.yaml
$ aitm poc run cart-overflow.yaml
# → finding capture · cart-overflow.yaml · screenshot.png

Three UIs, one bus

All three are thin clients of the same command bus. One token vocabulary styles every surface.

macOSFully native Swift/SwiftUI with an AppKit flow table. No web view, no Electron.apps/mac
WebA SolidJS UI built once and embedded in the binary, served over a WebSocket bridge.aitm web
TerminalOne Rust/ratatui binary for macOS and Linux. Keyboard-complete; degrades gracefully.aitm tui

Two languages, made to read

Extend the proxy in Rhai, and capture findings as declarative PoC YAML. Both are written to be read and written by people, not only agents.

Rhai plugin

addons/guard-admin-writes.rhai
fn on_request(flow) {
    let req = flow.request;
    if req.path.starts_with("/admin")
        && req.method != "GET" {
        if !req.headers.has("X-Admin-Token") {
            flow.set_response(403, #{}, "blocked");
            return halt();
        }
    }
}
