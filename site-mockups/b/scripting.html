Reference / Rhai scripting

Rhai scripting

Extend the proxy without recompiling it. Scripts are Rhai — written to read like intent, not ceremony — and run in a default-deny sandbox.

Load one or more scripts at startup. Every hook is optional; write only the ones you need.

shell
$ aitm --script addons/tagger.rhai --script addons/guard-admin-writes.rhai

Capability model

The engine is built raw: a script has no filesystem, network, process, environment or clock. Its only powers are the host functions aitmproxy registers — so network and browser calls always pass the scope, rate-limit and SSRF guards. There is no second code path out.

LimitDefaultWhy
max_operations2,000,000a runaway script can't stall the proxy
max_call_levels64bounded recursion
max_string / array10 MiBbounded memory per hook
max_modules0imports are forbidden
evaldisabledno dynamic code
The sandbox contains mistakes, not hostile operators. Scripts are operator-authored for an authorized assessment. The guarantees are containment, scope integrity and a bounded blast radius.

Hooks

A script reacts to the flow lifecycle. Each hook receives an owned snapshot and records effects applied after it returns (and discarded on error) — a script never holds a live borrow of the flow.

HookFires
load(reg)once, to register options and commands
on_request(flow)a full request is available
on_response(flow)a full response is available
on_ws_message(flow, msg)a WebSocket frame passes
on_error(flow, err)the flow errored

The flow API

Reads are forgiving — a missing header or field returns ""/null rather than throwing. Writes read like JavaScript: template literals, in, indexed headers and #{ … } maps.

OnMembers
flow.id .kind .is_replay .marks .comment · .mark(tag) · .set_response(status, headers, body) · .intercept() .resume() .kill() .backup() .revert()
request / response.method .url .path .query .headers .body .bytes · .set_json(map) · response adds .status
headers.get(k) .set(k,v) .remove(k) .has(k) .keys() · headers["X-Api"] = "1"
msg (WebSocket).direction .opcode .text .data · .drop()
verdicthalt() stops the chain · finding(#{ … }) records an observation

Examples

A readable plugin

Tag every request, flag server errors, and expose a liveness command. Nothing here is required but the hooks you want.

addons/tagger.rhai
// add a header to every request, flag 5xx responses, expose a command.
const NAME = "tagger";
const API  = "1";

fn load(reg) {
    reg.add_option("tag", "seen-by-aitm", "value for the X-Aitm header");
    reg.add_command("tagger.ping", "liveness check", |args| "pong");
}

fn on_request(flow) {
    flow.request.headers.set("X-Aitm", option("tag"));
}

fn on_response(flow) {
    if flow.response.status >= 500 {
        flow.mark("server-error");
        log.warn(`5xx on ${flow.request.path}`);   // template literal
    }
}

Real control flow

Short-circuit writes to /admin that lack a token, and record a finding for the agent to collect.

addons/guard-admin-writes.rhai
fn on_request(flow) {
    let req = flow.request;

    if req.path.starts_with("/admin") && req.method != "GET" {
        if !req.headers.has("X-Admin-Token") {
            flow.set_response(403, #{ "Content-Type": "text/plain" }, "blocked by aitm");
            finding(#{
                name: "unauthenticated admin write blocked",
                severity: "medium",
                flow_id: flow.id,
                detail: `${req.method} ${req.path} without X-Admin-Token`,
                tags: ["access-control"],
            });
            return halt();                       // nothing forwarded
        }
        req.headers.set("X-Reviewed", "aitm");   // otherwise tag and continue
    }
}
The same script: step is available inside a PoC document as an escape hatch when the matcher DSL can't express the logic.
