# Full-app review — 2026-10-31

A bama-suite pass over every surface of the macOS app (`mac-design` rules, `ux-design`
states/words/hover/a11y, `layout-grid`, `swift-swiftui`, `test-mac-app`, `performance`,
`improve-architecture`). Inputs: 116 light + dark snapshots of every sidebar page, every
`SnapshotScene` and every Settings tab (`DEV_TAG=review tools/snap-dev.sh` on `60c2dc8`), four
parallel reviewer reads (flow list + chrome, inspector, aitmproxy panels, settings + code quality),
and the gates: `swift test` 335 + 27 green, `check-layout.swift` PASS on every layout file,
`grid-lint` PASS, in-app self-test **8 of 121 red**.

This file is the spec and plan for the fix waves below. Findings carry the reviewer's rule
number from `mac-design/design-rules.md` where one applies.

## What is strong (keep)

- One token system (`Tok`/`DynamicColor`, generated) gives correct light/dark/Increase-Contrast
  by construction; dark mode is a real second palette.
- The editorial system holds everywhere: tracked small-caps labels, mono data, hairlines not
  cards, hue only on data. The dense flow list, the single saturated intercept bar, and the
  underline tab language are right.
- Honest degraded states already exist where the core lacks a verb (Timing, Scripts source,
  L4 on an embedded core), and `ContentUnavailableView` carries a first action.
- Kit-first testing with real seams (`FlowActions` two adapters, `FakeBusServer`).

## Waves

- **Wave 1 — truth and fit** (this branch, `claude/macos-review-fable`): A1–A4, A6–A9, B1–B7,
  B11, B12, C1–C3, C5, D1, D3. File-disjoint slices: Inspector/, Panels/ (not Overview),
  Shell/{InterceptBar,FilterBar,ChipBar,StatusBar,ShellToolbar,RulesSheet,ScopeSheet,
  CommandPalette,ComposeSheet}, plus SelfTest/Snapshot/FlowQuery.
- **Wave 2 — fill and honesty**: Overview lower half (Methods, Clients, Slowest, Recent errors,
  Largest responses, L4 sessions; tiles act as filters), B8 Pinned/Saved, B9, B10, C4, A5.
- **Wave 3 — architecture**: the verb table (E), Clear with Undo (D2), bus poll when hidden,
  a `HoverRowStyle` for the three hover rows, responsive flow columns (auto-hide low-priority
  columns below the minimum sum instead of a horizontal scroll).
- **Wave 3 — harness (from the orchestrator, 2026-10-31; shipped the same day)**: the
  app's connection settings (`bus.*`, `proxy.*`, `capture.enabled`) now come from
  `Store.defaults`, chosen once per process by `SettingsDomain` (Kit): the real defaults in a
  normal launch, an isolated suite `com.mrbrutti.aitmproxy.harness` (wiped at startup) when
  `APP_STORE`, `APP_LIVE`, `APP_SNAPSHOT` or `APP_FIXTURES` is set, or `APP_DEFAULTS_SUITE=<name>`
  kept as is. `BusEndpointSettings` (BusClient) is the pure (settings, config) → endpoint
  resolution with its own tests, so Settings ▸ Bus residue can neither steer `selftest-live.sh`
  nor be written by it. Under `APP_LIVE=1` the active core defaults to external and
  `APP_LIVE_OPERATOR_TOKEN` (the config's `mcp.operator_token`, read by the script) makes the
  run an operator: an agent is refused `flow.intercept` under the default `auto` policy, and the
  policy is not settable from the CLI. The "spin at startup" was not a `settle()` loop (those
  were already bounded): AppKit opens a bare command-line word (`external` in
  `--selftest -bus.activeKind external`) as a document, SwiftUI then never opens the main
  `Window`, so the `.task` that starts the self-test never fires and the process idles
  (measured 0 % CPU, main thread in the run loop). `SelfTest.armWatchdog` now fails such a run
  after 15 s and any run not finished after 240 s. `build.sh` builds the Network Extension and
  installs to `/Applications` only with an explicit `--ne`; it prints the bundle it is about to
  replace and refuses a different `CFBundleShortVersionString` without `--replace`.
  `tools/snap-dev.sh` (`DEV_TAG`) stays the iteration loop; both self-test scripts take
  `APP_BIN` to run a snap-dev bundle.
- **Routed to the NE session** (owns the files): `ShellView` Saved case + DropOverlay copy +
  AppsNeedsExtension copy; `SettingsView` D4 items incl. Keychain token.
