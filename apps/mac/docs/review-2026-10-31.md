# Full-app review — 2026-10-31

A bama-suite pass over every surface of the macOS app (`mac-design` rules, `ux-design`
states/words/hover/a11y, `layout-grid`, `swift-swiftui`, `test-mac-app`, `performance`,
`improve-architecture`). Inputs: 116 light + dark snapshots of every sidebar page, every
`SnapshotScene` and every Settings tab (`DEV_TAG=review tools/snap-dev.sh` on `60c2dc8`), four
parallel reviewer reads (flow list + chrome, inspector, aitmproxy panels, settings + code quality),
and the gates: `swift test` 335 + 27 green, `check-layout.swift` PASS on every layout file,
`grid-lint` PASS, in-app self-test **8 of 121 red**.

This file is the spec and plan for the fix waves below. Findings carry the reviewer's rule
number from `mac-design/design-rules.md` where one applies.

## What is strong (keep)

- One token system (`Tok`/`DynamicColor`, generated) gives correct light/dark/Increase-Contrast
  by construction; dark mode is a real second palette.
- The editorial system holds everywhere: tracked small-caps labels, mono data, hairlines not
  cards, hue only on data. The dense flow list, the single saturated intercept bar, and the
  underline tab language are right.
- Honest degraded states already exist where the core lacks a verb (Timing, Scripts source,
  L4 on an embedded core), and `ContentUnavailableView` carries a first action.
- Kit-first testing with real seams (`FlowActions` two adapters, `FakeBusServer`).

### E. Architecture (improve-architecture check-in)

**One verb table for row actions — Strong, carried since M1, now six copies.** Titles, keys and
enabled rules live in `InterceptBar`, `App.swift` Flow menu, `FlowTableView.buildRowMenu`,
`Session+Verbs.perform`, `FlowRowActions.keyDown`, and `CommandMap`; copies already disagree
(B3). Interface (Kit, values): `FlowVerb`, `VerbContext(row, pendingEdits, pinned, selectedCount,
isInterceptTarget)`, `VerbItem(verb, title, key, enabled, group, disabledReason)`,
`VerbTable.items(for:)`, `VerbTable.verb(forKey:in:)`. Five commits: Kit + tests → `perform`
the only entry → `buildRowMenu` iterates (moves to `FlowTableView+Menus.swift`) → Flow menu +
bar + `CommandMap` from the table → delete literals, update `ARCHITECTURE.md`. Proof: snapshots
byte-identical except B3, self-test S-069 green, `VerbTableTests`.

Other cards: bus poll never slows when no window is visible (`BusService.pollLoop` 500 ms) —
Worth exploring, slow to 5 s when hidden; `Session` god model (75 stored properties, 28 views)
— Speculative until the verb table lands; test hooks compile into the shipping app —
Speculative; `EmbeddedCore.Child` `@unchecked Sendable` over a mutable flag — fix with a lock.
